Gokan SRS: Design System v1
1. Brand principles (the “why”)

Gokan SRS is a study instrument, not a game.

Design should:

Reduce cognitive load

Encourage focus and consistency

Feel calm, precise, and trustworthy

Avoid anything that:

Competes with the content

Feels playful or emotional

Tries to “motivate” through gimmicks

If in doubt, choose restraint.

2. Logo usage
Primary logo (Logo 1)

Use on:

Landing page hero

App splash screen

Marketing materials

Always on light background

Prefer generous whitespace

Secondary mark (Logo 3)

Use for:

Favicon

App icon

Header corner mark

Loading screens

Square-safe and legible at small sizes

Do not

Add shadows

Add gradients

Stretch or compress

Place on noisy backgrounds

4. Typography
English type system
Primary serif (headings, branding)

Source Serif 4

Free, high-quality, editorial

Excellent readability

Serious without feeling old

Use for:

Page titles

Section headers

Logo-adjacent text

Secondary sans-serif (UI, body text)

Inter

Neutral

Designed for interfaces

Pairs extremely well with serif

Use for:

Buttons

Body copy

Navigation

Labels

Japanese type system
Mincho (headings, kanji emphasis)

Noto Serif JP

Clean, modern Mincho

Works perfectly for 語感 logo

Excellent legibility

Gothic (UI text)

Noto Sans JP

Neutral and readable

Matches Inter visually

Typography rules

Never mix more than one serif + one sans per language

Avoid font weights below 400

Avoid letter-spacing tricks

Let hierarchy come from size and spacing, not decoration

5. Layout & spacing
Rhythm

Base spacing unit: 8px

Sections breathe; don’t cram

Content width

Max-width: 960–1100px

Reading comfort > density

Alignment

Left-aligned text almost everywhere

Center only for logos and empty states

6. UI elements
Buttons

Rectangular, subtle rounding (4–6px)

Solid background for primary actions

No gradients

No shadows unless extremely soft

Cards

Border over shadow

White background on off-white canvas

Clear separation, not “floating”

Animations

Minimal

150–200ms

Ease-in-out only

No bounce, no elastic

7. Tone & microcopy
Voice

Neutral

Direct

Encouraging without cheerleading

Examples

❌ “Awesome job! You’re on fire!”
✅ “Review complete.”

❌ “Oops! You missed one 😅”
✅ “Incorrect. Next review in 10 minutes.”

Language reinforces seriousness.

8. What this system communicates

Without saying it explicitly, your app tells users:

“This is a tool for people who are serious about Japanese.”

That’s exactly the audience that sticks around long-term.
